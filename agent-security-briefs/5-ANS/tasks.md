# ANS（智能体 Nexus） · 任务清单

## 已确认

- 已知定位：智能体 Nexus / 编排总控层。
- 已知关系：向下统一调度或编排身份、安全、网关、AI-BOM 等能力。
- 已知场景：多智能体协同、统一调度、运营管控、全生命周期安全管控。
- 已知来源：产品全景、产品关系图和整体技术架构均把 ANS 放在产品协同架构的顶层。

## 仅从其他资料推导

- ANS 可以作为统一管控入口承接资产、身份、策略、网关、风险告警和处置状态，但具体页面、模块和流程资料未覆盖。
- `ANS.md` 中提到的“智能体安全平台”“三中心协同”“全流程闭环”可作为整体产品方向的来源，但该材料未把每项能力明确归属到 ANS 模块。
- ANS 可能承担运营与审计视图聚合，但当前资料没有具体功能规格。
