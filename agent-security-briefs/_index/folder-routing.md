# 文件夹路由索引

本文件用于在读取具体产品资料前，先根据用户问题判断应该进入哪个产品文件夹，避免一次性读取过多上下文。

## 使用原则

1. 先读本文件，再决定产品目录。
2. 只读取命中的 1-2 个产品目录。
3. 不要把 `skills/` 当作产品资料目录；`skills/` 只提供回答流程。
4. 资料不足的产品目录只在用户明确点名时读取，不参与自动扩展回答。
5. 如果无法判断产品，先读 `0-产品全景/product-map.md`，仍不明确时只追问一句。

## 冲突判断

当一个问题同时像多个产品时，按问题核心动词判断：

| 核心动词 | 优先产品 |
|---|---|
| 发现、盘点、登记、清单、依赖、资产、供应链 | AI-BOM |
| 认证、授权、越权、意图、审计、追责、策略 | 智能体身份安全 |
| 拦截、入口、代理、网关、流量、调用控制 | 智能体安全网关 |
| 检测、识别、攻击、防护、风险行为 | 智能体安全 |
| 编排、调度、协同、总控 | ANS |
