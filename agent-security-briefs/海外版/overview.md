# 海外版产品组合

## 组合定位

海外版产品组合已形成，不是国内全产品矩阵的简单平移，而是以 **AI-BOM** 为主力产品，围绕 AI 资产透明、AI 供应链治理、影子 AI 发现和合规台账输出构建独立卖点；在此基础上，裁剪接入部分 **智能体安全**、**智能体身份安全** 能力，并共享 **智能体安全网关** 作为运行时入口防护底座。

一句话：海外版先帮客户把 AI 资产“看清楚、列明白、可追溯”，再按风险需要补上身份、访问控制、运行时检测和网关防护。

## 产品组合

| 层级 | 产品/能力 | 海外版定位 | 取舍 |
|---|---|---|---|
| P0 | AI-BOM | 主力产品，独立售卖 | 保留全量资产发现、AI-BOM 台账、SPDX 3.0、依赖拓扑、影子 AI 治理、合规报告 |
| P1 | 智能体安全网关 | 共享底座 | 保留统一入口、输入输出过滤、提示词注入/越狱防护、日志审计与告警 |
| P2 | 智能体安全 | 轻量能力包 | 保留 MCP/Skills/RAG 事前检测、运行时异常监测、事后审计溯源 |
| P2 | 智能体身份安全 | 轻量能力包 | 保留 Agent Card、身份目录、访问控制、链路审计；弱化国内合规与重型取证叙事 |
| P3 | ANS | 暂不作为主推 | 可作为大型客户统一运营与编排入口，不作为海外版首发主线 |

## 与国内版的差异

| 维度 | 国内版 | 海外版 |
|---|---|---|
| 主叙事 | 智能体安全全产品矩阵 | AI-BOM 为主的 AI 资产与供应链治理 |
| 合规语言 | 等保、关基、国标、行业监管 | SPDX 3.0、AI inventory、AI supply chain、audit readiness |
| 目标问题 | 全链路安全治理与合规落地 | 影子 AI、AI 资产不可见、模型/工具/API 依赖不透明 |
| 产品形态 | 多产品矩阵并行 | AI-BOM 主产品 + 可选安全模块 |
| 部署方式 | 私有化为主 | 本地化、混合云、边缘节点、云上资产接入 |
| 销售入口 | 安全合规、智能体平台建设 | AI inventory、AI governance、AI supply chain risk、Shadow AI |

## 海外版主线

1. **先盘点**：通过主动探测、被动流量分析、AI 指纹识别发现模型、智能体、MCP 工具、API、业务应用和 IT 基础设施。
2. **再建账**：按 AI-BOM / SPDX 3.0 思路生成标准化资产台账，解决 AI 资产口径不统一、人工 Excel 盘点不可靠的问题。
3. **看关系**：构建资产与代码、镜像、配置、服务、模型、工具、API 之间的依赖拓扑，支持影响范围分析。
4. **识别风险**：发现影子 AI、僵尸资产、未登记智能体、风险 MCP/Skill、异常调用链路。
5. **输出证据**：形成审计报告、资产清单、风险处置记录，为客户内部治理和外部审计提供证据。

## 可复用能力来源

- AI-BOM：资产发现、资产台账、依赖拓扑、影子 AI 治理、SPDX 3.0。
- 智能体安全：MCP 风险检测、Skills 风险检测、RAG 风险检测、事中监测、事后审计。
- 智能体身份安全：Agent Card、身份可信、意图驱动访问控制、全链路审计。
- 智能体安全网关：统一流量入口、实时检测、提示词注入/越狱/敏感泄露防护、日志与告警。
