# AI-BOM 海外版

## 一句话定位

AI-BOM 海外版是面向国际客户的 AI 资产发现与供应链治理产品，帮助企业持续发现、登记、追踪和审计自身使用的模型、智能体、MCP 工具、API、业务应用和 IT 基础设施。

它的核心卖点不是“中国监管合规”，而是 **AI inventory + AI supply chain transparency + Shadow AI discovery + SPDX 3.0 compatible reporting**。

## 解决什么问题

- 企业不知道内部到底有多少模型、智能体、工具和 API 在跑。
- 传统 CMDB 只能管理服务器、网络设备和软件 License，缺少模型、智能体、MCP、Prompt、知识库等 AI 原生字段。
- AI 应用依赖链复杂，模型、工具、代码、镜像、配置和服务之间关系不透明。
- 员工或业务部门私自使用外部 AI 工具，形成 Shadow AI 和数据外流风险。
- 安全、法务、审计团队无法快速拿出一份可信的 AI 资产清单和风险证据。

## 核心能力

| 能力 | 海外版保留内容 | 价值 |
|---|---|---|
| 自动资产发现 | 主动探测、被动流量分析、AI 指纹识别 | 发现模型、智能体、MCP 工具、API、业务应用和基础设施 |
| 标准化台账 | 基于 AI-BOM / SPDX 3.0 思路组织字段 | 形成可审计、可导出的 AI 资产清单 |
| 依赖拓扑 | 资产与代码、镜像、配置、服务、模型、工具、API 的关系图谱 | 支持风险定位、影响范围分析、变更追溯 |
| Shadow AI 治理 | 识别未登记、未审批、脱离管理的 AI 资产 | 帮助安全团队从“看不见”变成“可处置” |
| 生命周期管理 | 发现、入库、监控、告警、处置、下线 | 避免一次性盘点失效 |
| 合规与审计输出 | 资产报告、风险清单、处置记录 | 支撑客户内部治理、外部审计和供应链透明要求 |

## 海外版裁剪原则

保留：
- AI 资产发现和台账能力。
- SPDX 3.0 / SBOM 延展叙事。
- 多云、本地化、混合环境资产接入。
- 影子 AI、僵尸资产、依赖拓扑和审计报告。

弱化：
- 等保、关基、国内行业监管口径。
- 只面向国内政企/运营商的场景表达。
- 需要重型本地安全运营体系才能交付的能力承诺。

补强：
- AI supply chain visibility。
- AI model / agent / tool inventory。
- API and MCP dependency mapping。
- Audit readiness and governance reporting。

## 与其他海外版模块的关系

- **智能体安全网关**：AI-BOM 发现资产和调用关系，网关负责运行时入口防护、日志和告警。
- **智能体安全轻量包**：AI-BOM 提供资产对象，智能体安全对 MCP、Skills、RAG、知识库和运行时行为做风险检测。
- **智能体身份安全轻量包**：AI-BOM 提供资产底账，身份安全为智能体、工具和调用主体建立身份、权限和审计链路。

## 典型场景

| 场景 | 客户问题 | 海外版打法 |
|---|---|---|
| AI 资产摸底 | 不知道组织内有哪些 AI 服务和工具 | 用 AI-BOM 做全域发现和标准化台账 |
| Shadow AI 治理 | 员工私自使用外部 AI 或自建 Agent | 通过流量分析、指纹识别和资产登记发现未纳管对象 |
| AI 供应链透明 | 模型、工具、API 和代码依赖关系不清 | 输出依赖拓扑和影响范围分析 |
| 审计准备 | 安全/法务需要可证明的 AI 资产清单 | 导出资产清单、风险清单和处置记录 |
| 多云混合环境治理 | AI 资产散落在云、本地和业务系统 | 统一发现、统一台账、统一视图 |
