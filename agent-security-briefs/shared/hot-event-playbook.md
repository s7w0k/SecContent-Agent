# 热点事件 PR 操作手册

> 最近更新：2026-07-13
> 适用范围：市场和 PR 的内部选题、产品匹配和角度参考，不等同于最终对外发布口径。
> 可信度说明：事件匹配和金句是内部策划建议，不是已发生事实或产品承诺；发布前必须核验热点事实，并完成市场和产品确认。

> 给市场部用：什么热点来了 → 推哪个产品 → 用什么角度。

## 使用边界

- 已知事实：热点是否真实发生、事件细节和产品能力，必须以可靠来源及对应产品 brief 为准。
- 内部判断：首选产品、次选产品和传播角度是当前资料下的内部判断，仅供策划参考。
- 推断：由热点延伸出的影响、趋势或产品价值属于推断，不得写成已经发生的事实。
- 待确认：热点事实、产品技术表述、产品是否已发布，以及金句的具体使用场景，均需在发布前确认。
- 金句可以作为标题方向，但市场和产品确认后再对外使用。

## PR 发布流程

1. 热点出现 → 市场部查本表匹配产品
2. 从对应产品的 `market-brief.md` 取金句和角度
3. 如需技术细节 → 从 `architecture-brief.md` 取
4. 找产品负责人确认技术表述无误
5. 发布后把案例补录到对应产品的 `market-brief.md`「过往 PR 案例」栏

## 禁忌

- 不要预测未发生的安全事件
- 不要直接点名竞品
- 产品版本、交付范围或对外口径未确认时，不要承诺具体交付时间
- 技术细节以 `architecture-brief.md` 为准，不要发挥
