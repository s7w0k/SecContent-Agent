# 智能体安全 · 市场 PR 材料

## 可关联的热点事件类型

| 热点类型 | 可用传播角度 |
|---|---|
| Prompt Injection / 越狱攻击 | 企业 AI 安全需要同时关注提示词、语义和运行行为，而不只是传统网络入口。 |
| MCP 工具链攻击 | 工具调用链可能出现劫持、投毒、参数风险和数据污染，需要在准入和运行阶段持续检测。 |
| Agent Skill 投毒或恶意插件 | Skill 具备代码、依赖、外联和系统操作风险，需要静态、动态和运行时关联检测。 |
| 企业智能体误操作或数据泄露 | 用事中行为监测和事后调用链审计支撑风险阻断、溯源和处置。 |
| AI 应用上线前安全评估 | 以通用基线和智能检测组合做能力上架前的安全准入。 |

## 一句话金句

- “智能体安全要从上线前准入，延伸到运行中监测和事后可追溯。”
- “看清智能体、模型、Skills、MCP 工具和知识库的风险，才能让 AI 能力可信分发。”
- “AI 安全不止过滤内容，还要看调用链、行为和数据来源。”

以上为基于原文能力整理的传播表达，不代表对外效果或性能承诺。

## 传播角度速配

| 媒体/场景 | 推荐角度 |
|---|---|
| 安全垂直媒体 | Prompt Injection、越狱、MCP 劫持投毒和 Skill 供应链风险。 |
| 企业数字化媒体 | 智能体能力上架前检测，以及平台运行期间的风险可视化和审计。 |
| 合规与治理场景 | 日志留存、调用链展示、数据溯源和合规报告。 |
| 行业峰会 | 事前检测、事中监测、事后审计三段式智能体安全体系。 |

## 可复用素材

- “安全视图”架构：风险大屏、风险地图、合规报告。
- “智能体资产管理”闭环：同步与扫描、全量发现、统一收敛、持续监测、审计和预警。
- Skills 四阶段检测：开发、发布、加载、运行；可展示基线哈希、版本比对、签名绑定、行为监测和调用链审计。
- 事后审计链路：日志采集、数据分析、统一查询、调用链展示、威胁情报观测和数据溯源观测。

## 禁忌

- 不渲染或公开具体未授权客户事故，不把“XX 集团”案例写成公开客户名称。
- 不承诺“完全防住所有攻击”、零误报或所有场景都能阻断。
- 不把 PPT 提及的指标、覆盖率、延迟和硬件规格包装成已验证市场口径。
- 不把智能体安全网关的独立产品能力全部归入本平台。
- 不把本平台的资产管理视图包装成 AI-BOM 的全域资产台账和供应链治理。
