# 智能体安全 · 技术概要

## 总体功能架构

原文将平台分为六组能力：

1. **安全视图**：风险大屏、风险地图、合规报告。
2. **事前防御**：MCP 风险检测、Skills 风险检测、RAG/知识库风险检测。
3. **事中控制**：防注入、防越权、防投毒监测。
4. **事后溯源**：日志留存、告警溯源、审计报告。
5. **检测模型**：安全检测大脑、异常行为模型。
6. **原子能力**：数据脱敏、水印溯源、敏感识别。

智能体资产管理视图覆盖智能体、大模型、Skills、MCP 工具和知识库，原文描述了同步与扫描、全量发现、统一收敛、可视化管理、持续监测、合规审计和风险预警闭环。

## 事前检测

### 通用准入检测

原文的事前安全准入场景采用“通用基线 + 智能检测”：

- 通用检测：协议合规性、安全配置、组件漏洞和已知威胁等风险专项检测。
- 智能检测：MCP 深度检测、Agent 深度检测、Skill 深度检测和多模态知识检测。
- 检查内容包括能力描述字段和协议版本、密钥硬编码与敏感环境变量、开源框架/第三方库/模型文件的已知漏洞、提示词投毒、知识投毒、后门模型、逻辑缺陷和越权倾向。

### MCP 工具风险管理

可配置检测规则，并按全域、分域或资产自动扫描。原文明确列出 MCP 冲突、劫持、投毒、配置脆弱性、Web 漏洞和敏感数据检测，风险发现后可联动告警、处置、验证和复盘。原文还提到工具中毒、Rug Pull 和影子攻击等工具侧威胁。

### Skills 风险管理

覆盖发布、更新和运行阶段，采用静态扫描与动态沙箱分析，检查：

- Markdown/主描述文件、脚本代码和依赖风险。
- 数据流追踪和外联行为。
- 内容与元数据、代码与供应链、交互与数据流、执行控制与环境四类风险。

Skill 检测模型按 L1 规则与结构、L2 轻量模型、L3 语义复核、L4 运行时关联递进，可使用正则/YARA/AST/格式校验/基线哈希、小模型语义识别、LLM 裁判、数据流分析、行为监控和调用链审计。分阶段方案覆盖开发、发布、加载、运行，并支持阻断、人工复核、持续监控、隔离、下架和告警。

### 知识库风险管理

覆盖知识库入库、存储和调用，使用多模态识别与规则引擎进行全量/增量扫描，结合数据标签定位风险。检测范围包括敏感个人/商业信息、个保数据信息、违规内容、访问控制与身份管理风险、供应链风险和数据投毒；原文提到以小模型识别和关键词字典组合辅助精准定位及合规检查。

### 策略管理

原文描述了“安全策略集 -> 识别规则组 -> 原子检测能力”三层架构，支持 AI 小模型语义识别与关键词/正则字典组合、文本和代码等多模态扫描，以及 AND/OR/NOT 逻辑组合。命中策略后可直接拒答、敏感词脱敏/掩码、警告并放行或人工审核拦截。

## 事中监测

### 平台内的网关组件

智能体安全网关在本平台中承担事中监测和链路防护组件角色。原文描述其通过输入输出过滤、内容审查和上下文限制，覆盖用户输入、大模型规划、记忆数据存储、工具描述和响应、Agent 最终响应及跨 Agent 消息传递等环节。

`4-智能体安全网关/` 是独立产品目录。当前 brief 只把原文明确列出的网关能力作为平台事中监测能力，不据此扩展独立网关产品的完整能力范围。

### 语义和攻击防护

- 提示词注入：使用 NLP 模型识别“忽略前述指令”“泄露系统提示”等模式，可隔离注入内容、重构安全提示或拒绝响应；原文还提到在 RAG 检索召回环节增加 NLP 清洗。
- 越狱防护：识别角色扮演、虚构情境和翻译指令等变体，采用动态过滤和语义重定向。
- MCP 链路：监控多链提示流，识别劫持和投毒向量，可隔离异常链路段、重置提示状态或触发沙箱验证。
- 工具调用：扫描 RAG 检索结果、函数参数和外链响应，支持源头白名单验证、内容消毒和动态阻断高危工具交互。

### 行为与专项监测

原文将运行期监测分为语义安全防护、资产行为监测和专项能力深度监测：

- API 与网关资产防护：异常调用、高频访问和恶意重试。
- 会话与交互链路防护：会话劫持和未授权跳转。
- 数据流与隐私防护：输入、输出和内部流转中的异常访问与泄露。
- 资源与算力防护：推理、知识库查询等环节的算力消耗和滥用。
- MCP、智能体、模型和知识库专项监测：分别关注工具标识/签名、决策链路与行为一致性、推理和输出偏差、向量完整性与结果操纵。

## 事后审计与处置

风险分析以访问日志、安全告警、网络流量和上下文信息为数据基础，结合不良内容、智能体风险、敏感数据、威胁情报、行为、MCP 攻击和攻击路径分析，形成自动化告警和风险管理闭环。

审计溯源能力包括智能体日志留存、安全数据存储与分析、全链路日志采集、日志标准化、统一查询、调用链展示、IP/域名/URL/APT 威胁情报观测，以及泄露数据上传和水印解密溯源。处置侧支持系统通知、工单和人机联动，自动动作包括智能体注册/流量/权限限制、大模型访问阻断、MCP 服务暂停和工具禁止接入。

## 部署模式

原文描述本地化部署，支持物理机和云环境。示例集成链路为“智能体应用 -> 安全代理层 -> 后端服务”，安全代理层与智能体安全网关连接，智能体安全平台连接网关以统一管理安全策略；原文将其表述为无侵入式集成、现有代码改动小。

企业内网侧包括智能体安全平台、企业数据中心和企业私有云/物理服务器集群，后者列出 Kubernetes 集群、数据库集群和存储系统。

## 指标与限制

以下均为 **PPT 提及指标，需产品确认**，不得视为已承诺交付指标：

- 攻击阻断率 ≥99.9%，误报率 ≤0.1%。
- API 延迟 P99 ≤500ms，系统可用性 ≥99.95%，并发处理能力 ≥10000 QPS。
- 硬件要求：CPU 32 核+、内存 128GB+、存储 2TB+（原文称支持扩展）。
- MCP 事中链路页提及覆盖 95% 链路攻击场景、检测延迟 <30ms；提示词防护页提及覆盖 99% 常见注入向量、零误报率。这些同样需要产品确认。

原文未给出可直接作为交付承诺的部署周期、接口清单、容量验证报告或客户环境测试结论。

## 与其他产品的技术边界

- **智能体身份安全**：身份、授权、意图和责权审计是身份安全主线；本产品主线是风险检测、运行行为分析和安全审计。
- **智能体安全网关**：本产品使用网关作为事中监测组件；独立网关产品的统一入口、代理、流量和调用控制应以 `4-智能体安全网关/` 自身资料为准。
- **AI-BOM**：本产品可展示与安全检测相关的智能体、大模型、Skills、MCP 工具和知识库资产；全域 AI 资产发现、台账、依赖关系和供应链透明度仍属于 AI-BOM 主线。
- **ANS**：编排、调度、多智能体协同和总控不属于本 brief 已提炼的产品能力。
