# 智能体安全原始文档

## 资料分层

1. 产品 brief：产品根目录的 `overview.md`、`architecture-brief.md`、`sales-brief.md`、`market-brief.md`，用于日常问答和复用。
2. 结构化梳理稿：[亚信安全智能体安全平台解决方案 428-结构化梳理.md](./亚信安全智能体安全平台解决方案%20428-结构化梳理.md)，用于 brief 不足时按主题读取，保留原文证据、Mermaid 和页码映射。
3. 逐页抽取稿：[亚信安全智能体安全平台解决方案 428-原文图表整理.md](./亚信安全智能体安全平台解决方案%20428-原文图表整理.md)，只在核对原始页序、OCR、图表转写细节时读取。
4. 原始 PPT/PDF：当前目录未保存原始文件；需要确认页面视觉、指标、案例或部署规格时使用原始文件。

## 读取优先级

`产品 brief` -> `结构化梳理稿` -> `逐页抽取稿` -> `原始 PPT/PDF`

不要让日常问答直接依赖逐页抽取稿。指标、客户案例、部署规格、交付周期和对外宣传口径，必须回查结构化稿中的“待确认项”，并标注“PPT 提及，需产品确认”。
