# 合规红线清单（compliance-review）

## High（阻断发布）

1. 编造具体数据/指标（如「市场份额 40%」「增速 3 倍」无知识文件依据）。
2. 编造客户名、合作方、案例。
3. 虚构产品能力、版本号、交付时间。
4. 直接点名攻击竞品的负面措辞。

## Medium（必须修订）

1. 绝对化断言（「唯一」「最好」「第一」）缺少依据。
2. 未经确认的承诺（「将于 Q3 上线」等）。
3. 将推断表述为事实（缺少「预计」「可能」等限定）。

## Low（建议修订）

1. 术语使用不规范或首次出现未解释。
2. 空泛套话（「全面赋能」等无实据表述）。
3. 结构冗余或重复表述。

## 判定规则

- 无法从知识文件确认的事实性表述 → 至少 medium。
- 稿件引用与知识文件矛盾 → high。
- 来源标注缺失的关键数据 → medium。
