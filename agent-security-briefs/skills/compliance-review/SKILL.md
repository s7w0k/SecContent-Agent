# 合规审查 Skill

## 用途

对已生成的 PR 稿件做发布前红线检查，输出问题清单与建议。

适用场景：
- PR 初稿生成后、应用修订前
- 对既有稿件的合规复核

不适用场景：
- 稿件生成（用 draft-writing）
- 评分（用 scoring-knowledge）
- 对话问答

## 核心规则

1. 逐段检查稿件，对照红线清单（`references/red-lines.md`）。
2. 只依据稿本文本与知识文件判断，不自行补充事实。
3. 发现问题时输出：段落引用、问题类型、严重级别、修改建议。
4. 存在 high 级红线问题时，标记稿件为「不得直接发布」。

## 检查维度

| 维度 | 关注点 |
|---|---|
| 事实性 | 是否编造数据、指标、客户、案例 |
| 能力边界 | 是否虚构产品能力、版本、交付时间 |
| 竞品合规 | 是否直接点名攻击竞品 |
| 预测合规 | 是否预测未发生事件 |
| 表达合规 | 绝对化断言、未经确认的承诺 |

## 输出格式

```md
合规检查结果：通过 / 需修订（high: n, medium: n, low: n）

- 位置: 第 X 段
  问题: ...
  类型: ...
  级别: high|medium|low
  建议: ...
```
