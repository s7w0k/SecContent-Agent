# 市场 PR Skill

用于热点、PR、传播、新闻、公众号、舆情、金句、标题、能不能蹭等市场问题。

## 触发信号

用户提到：PR、热点、传播、金句、媒体、新闻、公众号、舆情、能蹭吗、角度、标题、稿件。

## 加载文件

1. 必读：`skills/common-rules.md`
2. 必读：`shared/hot-event-playbook.md`
3. 必读：相关产品的 `overview.md`
4. 必读：相关产品的 `market-brief.md`
5. 需要技术细节：加读相关产品的 `architecture-brief.md`
6. 跨产品组合传播：加读 `0-产品全景/product-map.md`

## 事件分级

| 级别 | 定义 | 响应方式 |
|---|---|---|
| S 级 | 重大事故、国家级新规、全国性新闻 | 深度观点稿，可联动产品矩阵 |
| A 级 | 行业报告、安全大会、友商动态、典型漏洞 | 首选产品深度角度，次选产品补充 |
| B 级 | 社交热议、公众号爆文、轻量话题 | 金句和短文，快速跟进 |

## 回答方式

推荐结构：

```md
事件匹配结论：能蹭 / 不建议蹭

首选产品：
- ...

传播角度：
- 角度 1：...
  金句：...
- 角度 2：...
  金句：...

操作建议：
- ...

禁忌：
- ...
```

## 表达要求

- 每次给 2-3 个可用传播角度。
- 每个角度配一句可直接做标题或小标题的金句。
- 角度必须基于产品真实能力，不编功能。
- 不预测未发生事件。
- 不直接点名攻击竞品。
- 产品版本、资料或对外口径未确认时，不承诺具体交付时间。

## 写稿边界

如果用户要求完整 PR 稿，可以给大纲、标题、导语和段落方向；除非用户明确要求生成全文，否则优先输出可供市场部加工的角度包。
