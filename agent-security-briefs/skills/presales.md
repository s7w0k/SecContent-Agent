# 售前 Skill

用于客户、打单、方案、优势、对比、报价、部署周期、案例等售前问题。

## 触发信号

用户提到：客户、打单、方案、对比、优势、卖点、报价、部署周期、能不能、有没有案例、多少钱。

## 加载文件

1. 必读：`skills/common-rules.md`
2. 必读：`X-产品名/overview.md`
3. 必读：`X-产品名/sales-brief.md`
4. 竞品深入对比：加读 `shared/competitor-brief.md`
5. 产品组合方案：加读 `0-产品全景/product-map.md`
6. 部署周期或集成方式：必要时加读 `X-产品名/architecture-brief.md`
7. brief 不足：查 `X-产品名/原始文档/`

## 回答方式

先给一句话结论，再展开。

推荐结构：

```md
一句话结论

核心差异：
- 传统做法 X，我们 Y
- 传统做法 X，我们 Y

客户应对：
- ...

风险或待确认：
- ...
```

## 表达要求

- 每次只讲 2-3 个核心卖点。
- 用客户业务语言，不堆术语。
- 对比时先讲传统方案或竞品痛点，再讲我们的解决方式。
- 报价、交付周期、客户案例如果资料没有，不要猜。

## 常见应对

| 客户问 | 处理方式 |
|---|---|
| 有没有客户案例 | 先查 `tasks.md` 和 `sales-brief.md`；没有就说资料未覆盖，可先看方案架构和试点状态 |
| 多少钱 | 没有公开报价就建议咨询商务，同时帮助梳理需求范围 |
| 部署多久 | 先查架构文档；没有就说取决于客户环境和智能体规模 |
| 跟某竞品比 | 读 `sales-brief.md` 和 `shared/competitor-brief.md`，推断项要标注 |
