# 智能体安全产品速查

本文件是给不识别 `CLAUDE.md` 的 AI 工具看的兼容入口。它不替代产品资料，也不改变 `CLAUDE.md` 的路由逻辑。

## 读取顺序

1. 先阅读本目录下的 `CLAUDE.md`，了解入口规则。
2. 阅读 `_index/folder-routing.md`，按问题选择 1-2 个产品目录。
3. 阅读 `skills/common-rules.md` 和对应身份 skill：`presales.md`、`architect.md` 或 `market-pr.md`。
4. 阅读命中产品目录的 `overview.md`，再按问题读取其他 brief。
5. brief 不足时，再查对应产品的 `原始文档/`；原始文档也没有，就说明“资料未覆盖”，并记入 `qa-log.md`。

## 产品状态与资料边界

- `1-智能体身份安全/`、`2-智能体安全/`、`3-AI-BOM/`、`4-智能体安全网关/` 和 `5-ANS/` 均为已开发产品；`海外版/` 已形成产品组合。
- 产品已开发完成不代表所有能力、版本、指标、案例、部署和交付信息都已确认，回答仍必须以文件中的明确内容为准。
- 资料覆盖不足时，先查对应 `原始文档/`；原始文档也没有就说明“资料未覆盖”，不要自动脑补能力。

## 重要边界

`skills/` 只写回答流程，不是产品事实来源。产品事实来自产品目录、`0-产品全景/`、`shared/` 或对应的 `原始文档/`。`原始文档/` 仅用于 brief 不足时兜底，不是常规第一入口。

涉及 PPT 指标、客户案例或部署规格时，标注“PPT 提及，需产品确认”。无法从资料确认的功能、交付时间、性能指标、客户案例和竞品结论，不要自行补充。
