# AI-BOM 原始文档说明

本目录同时保存产品方案 brief 的来源材料。为控制 Agent 上下文，按问题所需的最小范围读取，不要在常规问答中一次性加载全部原始文档。

## 文件用途

| 文件 | 类型 | 什么时候读 | 不适合做什么 |
|---|---|---|---|
| `AI-BOM-asset-management-solution-20260521.md` | PPT 逐页抽取稿 | 需要核对页码、逐页原文、图表结构、页面截图细节时读取 | 不作为常规问答的首选来源，不用于替代产品 brief |
| `AI-BOM资产管理解决方案-完整梳理.md` | 方案完整梳理稿 | 产品 brief 不足，或需要深入了解方案架构、能力、场景和边界时读取 | 不把其中的示例截图数字直接当作真实客户数据 |
| `亚信安全AI-BOM资产管理解决方案.pptx` | 原始 PPT | 仅在人工进行页面视觉复核，或必须确认视觉布局、截图、指标、案例、部署规格时打开 | 不作为 Agent 常规读取文件，不作为轻量资料包的默认上下文 |

## Agent 读取优先级

1. **常规问答**：优先读取 `3-AI-BOM/` 根目录的产品 brief，按问题选择 `overview.md`、`sales-brief.md`、`architecture-brief.md`、`market-brief.md`，不先读本目录大文件。
2. **brief 不足**：再读取 `AI-BOM资产管理解决方案-完整梳理.md`，只定位到回答所需章节。
3. **页码、图表、截图细节**：确有需要时才读取 `AI-BOM-asset-management-solution-20260521.md` 的对应页面，避免全文加载。
4. **视觉复核**：由人工打开 `亚信安全AI-BOM资产管理解决方案.pptx`；PPT 不是 Agent 常规问答来源。

读取链路可简写为：`产品 brief` -> `完整梳理稿` -> `逐页抽取稿` -> `PPT 人工视觉复核`。

## 大文件处理建议

- 当前 PPT 约 101 MB，不建议作为轻量 ZIP 资料包的默认读取内容。
- AI 常规问答不应读取 PPT；需要视觉确认时由人工打开，或由人工先指定页码和问题。
- 如后续需要长期版本管理，优先考虑外链、制品库或 Git LFS，不在本 README 中新增脚本或复杂索引。

## 已知边界

- PPT 中带“示例”水印的界面和数字只表示方案展示，不能直接表述为客户真实数据或已交付结果。
- 涉及 PPT 指标、客户案例、部署规格等信息时，统一标注：**PPT 提及，需产品确认**。
- brief 和原始文档均未覆盖的信息，写“资料未覆盖”或记入待确认，不自行补充产品功能、性能、交付时间或案例结论。
- 不修改本目录中的逐页抽取稿、完整梳理稿和 PPT 文件。
